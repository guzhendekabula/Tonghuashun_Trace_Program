# 迹线 TRACE · 股价异动解释工作台

React + TypeScript + Vite 的纯前端笔试 Demo。三支虚构股票、K 线、事件时间线、来源证据和浮动聊天助手。全部业务数据由本地固定规则生成，不请求真实行情或模型服务。

## 启动

Node.js 20.19+（推荐 24 LTS），npm。

```bash
npm ci
npm run dev
```

打开终端给出的地址。其他命令：

```bash
npm test
npm run lint
npm run build
npm run preview
```

依赖首次安装需要网络；安装完成后网页运行不需要外部服务。生产产物为 `dist/`，可部署到静态托管。

## 演示流程

1. 默认进入澄芯科技最近一个异动日；切换三支股票，观察上涨、下跌和证据较弱的场景。
2. 点击日 K 更新日期、事件时间线和详情。月 K 显示三根，点击月份回到日 K；时 K 显示选中交易日四个区间。
3. 点击时间线事件查看原始发布时间、交易所时间、映射日期、来源和本地证据。
4. 点击右下角助手，自动提交当前日期分析，逐步输出模拟回答。快捷问题与输入框均可使用；自由文本只进行有限关键词匹配，未知问题给出引导。
5. 点击已完成回答下的证据引用返回事件；切换日期停止未完成输出。收起助手保留记录，刷新页面清空。
6. 顶部演示场景可以触发加载、无行情、无关联事件、范围外事件、异常时间、异常行情、日历不足、证据不足。选择“正常数据”恢复。

## 数据与规则

`src/lib/market.ts` 定义 Candle、Event、股票、模拟日历、固定行情及事件。数据覆盖 2026 年 4—6 月；周末及 5 月 1、4、5 日作为模拟休市日，日历延长到 7 月用于尾部事件映射，不声称还原真实交易所假期。

- 三支虚构股票使用内部 SIM 代码。时 K 固定生成且没有随机性，聚合为日 K 和月 K；OHLC 取首开、末收、最高、最低，成交量求和。
- 小时区间：09:30–10:30、10:30–11:30、13:00–14:00、14:00–15:00。
- 日级绝对涨跌幅达到 5% 为异动；首日没有前收盘价不计算。第 21 和第 49 个交易日是固定异动场景。
- 事件包含 id、股票关联、标题、带时区发布时间、类型、模拟来源、摘要、证据摘录及观点标识。财务证据内置报告期、收入、利润、同比和披露时间，不依赖外链。
- 时间先转 Asia/Shanghai，再映射。交易日 15:00 之前（含午休）归当日；15:00 及以后、非交易日归下一交易日。无时区、非法时间和日历不足不猜测日期。
- 公告、新闻、行业事件、财务披露均有示例。证据是本地模拟原文摘录，不是真实资料。

## Agent 实现

本地 `answer` 函数按股票、日期、意图筛选事件并生成结构化解释；React 定时器每 35ms 追加一段文字，支持停止。用户上下文保存在每条消息中，证据按钮引用原始上下文。

回答区分事实、观点、时间相关性和因果假设。有效证据为中置信度，缺少证据为低置信度，并始终声明因果未证实；这是演示规则，不是模型概率。不支持自由对话、真实推理和外部查询。事件与财务材料在本版本采用紧凑内嵌结构，而非独立数据库表。

## 验证

`npm test` 使用 TypeScript 编译纯函数模块和 Node 内置测试器，不增加测试运行时依赖。覆盖盘后、非交易日、证据不足、收盘边界、跨时区、异常时间、日历不足、三周期聚合及响应兜底。页面联动需在浏览器中手动验收。

## 已知限制

- 模拟价格和休市安排不代表真实证券市场，内容不构成投资建议。
- SVG 图表支持悬停、键盘选中、周期切换，不包含专业交易终端的缩放和指标。
- 月 K 只覆盖三个月；数据及事件数量为最小演示规模。
- 异常行情场景为固定错误展示，加载场景持续展示以供评审观察，可手动恢复。
- 当前没有后端持久化、多轮语义记忆或自动滚动聊天功能。
